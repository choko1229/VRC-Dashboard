# ゲームログ収集エージェント

VRChatを起動しているPC上で動かす、ダッシュボード本体とは別プロセスの常駐スクリプトです。
VRChatクライアントのローカルログファイル（`output_log_*.txt`）を監視・解析し、訪問した
インスタンスごとの「プレイヤー参加/退出」「動画再生URL」をダッシュボードへ送信します。

VRChat公式APIには、フレンド以外の参加者の入退室や動画再生URLは一切含まれていません（これらは
VRChatクライアントがローカルに出力するログファイルにのみ存在します）。そのためダッシュボード
本体（Pterodactyl等のリモートサーバー）とは別に、このエージェントをVRChatを起動している
PC上で動かす必要があります。

## 必要なもの

- Python 3（標準ライブラリのみを使用するため追加のpipインストールは不要）
- ダッシュボードの `/game-log` ページで、管理者アカウントが発行したAPIキー

## 使い方

```bash
python gamelog_watcher.py --server-url https://your-dashboard.example.com --api-key <発行したキー>
```

設定を毎回引数で渡したくない場合は、このディレクトリに `gamelog_agent_config.json` を作成すると
読み込みます（`--config` で場所を変更可能）。

```json
{
  "server_url": "https://your-dashboard.example.com",
  "api_key": "..."
}
```

VRChatを起動した状態でこのスクリプトを起動しっぱなしにしておくと、ログの更新を検知して
自動的に送信します（Windowsのタスクスケジューラ等での自動起動を推奨します）。

## 制限・注意事項

- ログ書式は非公式で、VRChatクライアントの更新により変わる可能性があります。うまく取り込まれ
  ない場合は `gamelog_parser.py` の正規表現を実際のログに合わせて調整してください。
- 初めて見るログファイルは過去分を読み込まず、末尾（起動時点）から追跡を始めます。
- サーバーへの送信に失敗した場合は次回送信時にリトライします（最大約5000件までバッファし、
  それを超えると古いイベントから破棄します）。
- 送信済みの位置は `gamelog_agent_state.json`（`--state-file` で変更可能）に保存されます。
